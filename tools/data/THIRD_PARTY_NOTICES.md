# Third-party notices — brush preset library (brush_tips/)

The bundled paint-op presets (.kpp) are data files extracted from Krita's
official default resource bundles and interpreted by this project's own
engine. No Krita code is used, linked, or distributed; Krita itself is
GPL-3.0, and consuming the documented .kpp data format does not make this
project a derivative work of Krita.

## Bundled sources (both official Krita default bundles)

| Folder | Presets | Source | License |
|---|---|---|---|
| `Krita_4_Default_Resources/` | 117 | Krita 4 Default Resources bundle | **CC-0** (declared in the bundle's own `meta.xml`, contact `foundation@krita.org`) |
| `Krita_3_Default_Resources/` | 131 | Krita 3 Default Resources bundle | **CC-0** (same declaration) |

Authors, per the bundles' own metadata:

- Krita 4 bundle: Deevad (David Revoy), with derivations of brushes by
  Ramon Miranda, Razvanc, Radian, Wolthera, Storm, Scottyp and others.
- Krita 3 bundle: Timothée Giet, Ramon Miranda, David Revoy, and others.

CC-0 places no attribution requirement; the credit above is given as a
courtesy to the authors. License declarations were verified in the
`meta.xml` inside each official `.bundle` (Krita Foundation, 2018).

## Deliberately excluded from this distribution

- `RGBA_brushes` (Ramon Miranda): the bundle metadata declares its license
  only by reference ("same as default brushes in Krita"); not redistributed.
- Krita-5.3-era user-preset-folder packs (e.g. `j) WaterC *` watercolor
  series): no per-file license statement; not redistributed.

Excluded entries are also absent from `brush_lib.json` (the registry is
regenerated by `tools/preset_pack.py`, which extracts from the two
official bundles only).
