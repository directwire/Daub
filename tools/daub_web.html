接笔 · Agent 直连 MCP Tools

画坊的完整工序封装为 MCP 工具：规划、直出、分层修正、擦除补笔、过程视频。 任何 MCP 客户端一条命令接入——引擎在本机，数据不出坊。

接入 · Register 
claude mcp add -s user daub -- python /path/to/daub/tools/daub_mcp.py

清单由 daub_mcp.py 实时供给，引擎侧增删工具此页自动跟上。 规划返回 job_id，daub_wait 收货——Agent 作画，与人在工作台走同一套工序。
